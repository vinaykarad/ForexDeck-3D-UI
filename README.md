# Forex 3D Trading Frontend — README

This project is a **frontend demo** for a Forex trading platform with **3D animations**, **interactive buttons**, and a modern glassmorphism-inspired UI. It is built using only **HTML, CSS, and a bit of JavaScript** — no frameworks required.

---

## 🚀 Features
- 3D rotating cube representing different currency pairs.
- Animated forex cards with hover lift effects.
- Sparkline charts animated with SVG `<animate>`.
- 3D press illusion buttons for Buy/Sell actions.
- Glassmorphism panels for Quick Trade, Tools, and Account.
- Fully responsive design (mobile & desktop).

## ⚡ Getting Started

### 1. Clone or Download
Clone the repository (or copy the single HTML file):
```bash
git clone https://github.com/yourusername/forex-3d-frontend.git
cd forex-3d-frontend
```

Or just download the `index.html` file.

### 2. Open in VS Code
1. Open the folder in **Visual Studio Code**.
2. Make sure you have the **Live Server** extension installed.

### 3. Run the Project
- Right-click on `index.html` → **Open with Live Server**.
- Or open the file directly in any modern browser (Chrome, Edge, Firefox).
